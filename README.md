# Sound Icons

Turn your favorite sounds into beautiful, customizable Android home screen widgets.

Instead of opening an app and searching through a list of sounds, Sound Icons lets you place individual sounds directly on your Android home screen as interactive widgets. A single tap instantly plays the assigned audio.

---

## Features

### Interactive Sound Widgets

* One-tap audio playback
* Multiple widgets for different sounds
* Independent widget configuration
* Fast playback without opening the app

### Custom Artwork

* Import images from your device
* Crop icons with built-in editor
* Circle, rounded-square and square crop styles
* High-quality icon rendering

### Adaptive Widgets

Widgets automatically adapt to different launcher sizes.

Supported layouts include:

* Icon Only
* Icon + Name
* Dynamic resizing
* Automatic layout adjustments
* Transparent widget background

### Sound Management

* Import custom audio
* Rename sounds
* Favorites
* Adjustable playback volume
* Image editing
* Widget support

### Modern Android UI

* Material 3
* Dark theme
* Responsive layouts
* Smooth animations
* Optimized for modern Android launchers

## Project Goals

Sound Icons aims to make audio feel like a first-class part of Android personalization.

Every sound becomes its own home screen icon that behaves like an application while playing custom audio instantly.

The focus is on:

* Speed
* Simplicity
* Beautiful UI
* Customization
* Native Android experience
